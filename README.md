# Ninja Escape v1.0.0

A complete browser-based voxel escape adventure built for **GitHub Pages** and installable as a **Progressive Web App**. It is designed primarily for landscape tablet play, while also supporting desktop/laptop keyboard + mouse.

## The game

You play a ten-year-old boy captured by ninjas and locked into a sequence of tests. Escape six themed rooms, navigate five mazes, rescue earlier test subjects, collect food and crafting components, discover impossible shadows, build tools, complete mini-games and collect the five code fragments that open the final vault.

The game contains:

- 6 escape rooms: Dungeon, Cold, Hot, Garden, Dragon and Money/Vault.
- 5 procedurally generated but deterministic mazes, each matching the preceding escape-room theme.
- A five-fragment final vault code.
- 10 mini-game systems: memory, whack-a-mole, rapid timer race, imperfect block stacking, moving-bucket ball drop, block pushing, bridge building, Monty Hall, dance-pattern memory, falling-item catching and a parkour runner.
- Prisoner-rescue tasks.
- Hunger and food.
- Component collection and crafting: bow, arrows and stone spear.
- Tool-gated secret caches.
- Hidden clue shadows and dangerous living shadows.
- Automatic local save/continue.
- Procedural WebAudio sound effects and ambient themes (no external audio assets required).
- Fully code-generated voxel models, weather, dragons, dancing ninja pandas and themed scenery.
- Touch joystick + drag-look + ACTION/JUMP controls for tablets.
- Keyboard/mouse controls for desktop.
- Offline-capable PWA service worker generated by `vite-plugin-pwa`.

No backend is required.

## Controls

### Tablet / phone

- **Left circular joystick:** move.
- **Drag on the right side of the game:** look around.
- **ACTION:** interact with whatever is under the crosshair.
- **JUMP:** jump.
- **Backpack icon:** inventory, food and crafting.
- **Pause icon:** pause/restart options.

Landscape orientation is strongly recommended and the app displays a rotate notice on portrait touch devices.

### Desktop / laptop

- **WASD / Arrow keys:** move.
- **Mouse:** look (click the game to capture the pointer).
- **Space:** jump.
- **E:** interact.
- **C:** backpack/crafting.
- **Esc:** pause / release pointer.

## Updating the existing `Nearborn/ninja-escape` repository

Your GitHub Pages pipeline is already working. The safest update is to keep the existing repository and replace the game files with the contents of this package.

### Option A — Git command line (recommended if available)

Copy this project's contents into your local `ninja-escape` repository, preserving `.github/workflows/deploy.yml`, then:

```bash
git add -A
git commit -m "Build full Ninja Escape game"
git push
```

GitHub Actions will build and deploy it automatically.

### Option B — GitHub website

On the repository's **Code** page choose **Add file → Upload files** and upload/drag these from the extracted project:

- `index.html`
- `package.json`
- `vite.config.js`
- the complete `src/` folder
- the complete `public/` folder
- `scripts/` (optional, but useful for testing)
- `README.md`

You can leave the already-working `.github/workflows/deploy.yml` in the repository exactly where it is. The workflow bundled here is equivalent and uses `npm install`, so it does not require a lock file.

Commit the upload to `main`. Then open the **Actions** tab and wait for **Deploy game to GitHub Pages** to get a green tick.

The game URL is:

`https://nearborn.github.io/ninja-escape/`

Because Vite derives the GitHub repository name during the Actions build, the correct `/ninja-escape/` base path is set automatically.

## Local development

Requires Node.js 22 or newer.

```bash
npm install
npm run dev
```

For a production build:

```bash
npm run build
```

Logic/data checks that do not require a browser:

```bash
npm run test:logic
```

## Save system

Progress is stored in browser `localStorage` under `ninja-escape-save-v1`. The game automatically saves stage progress, completed tests, inventory, code fragments, hunger, rescued people and secrets.

The pause menu includes **Erase save & restart**.

## Design philosophy

The game is intentionally self-contained. Voxel scenery, characters, particles, signs and sound are constructed at runtime rather than downloaded as large models or audio files. This keeps the PWA lightweight and makes it suitable for ordinary tablets and GitHub Pages.

Core progression cannot be permanently blocked by an optional secret or a crafted tool. Crafting gives shortcuts/rewards and encourages exploration, but a player can always complete the story. Falling into lava or being caught by a shadow sends the player back to the current stage's safe spawn rather than deleting progress.
